# Connection logos

Bundled from the Simple Icons source repository. Google, Notion, Obsidian,
Linear, Jira, and Confluence use tag 16.0.0; Microsoft uses tag 11.0.0 (the
mark was removed from newer catalogues). The screen renders these marks in
monochrome using the current theme. No runtime logo request is made.

Source: https://github.com/simple-icons/simple-icons
